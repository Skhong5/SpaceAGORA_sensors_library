## Residual Risk

The static naming rule can still accept a wrongly named value as an RNG when the call has the required argument shape. In particular, it cannot distinguish a two-argument default-stream overload such as `rand!(rng_buffer, Float64)` from an RNG-plus-destination call by type. This change rejects the four requested one-argument forms; it does not prove that every in-place call uses a caller-owned stream. Indirect aliases, macro-generated calls, broadcast calls, type/dispatch behavior and stream provenance are outside this check. Legitimate RNG expressions that are not a named identifier or field must be bound to a suitably named variable before a checked call. Parsing relies on the bundled parser already used elsewhere in the repository's Julia 1.12 gates. The existing explicit global-stream pattern checks retain their textual limitations. Behavioral tests remain necessary to establish stream ownership and reproducibility.

The test file also receives independent appended testsets from active branches, so any overlapping end-of-file merge must retain each complete testset and rerun the controls.
