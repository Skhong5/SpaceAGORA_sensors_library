## Findings

No unresolved correctness findings. Independent review identified and repaired:

1. Relative duration addition could round one ULP beyond a valid horizon, such
   as 0.1 + 0.2 at 0.3 seconds. Finite relative deadlines may now snap by one ULP;
   explicit deadlines and materially late transitions remain strict.
2. Ensemble export initially omitted the new mission sidecar from its protected
   inputs. Every sample's history is now protected, including symlink and
   hardlink aliases, with public-export regression coverage.
3. In the companion, a selector retaining its active value prevented jumping to
   the current segment's start or repeating a transition jump. Jump selectors
   now reset to a prompt; the active segment has its own live label. Real-browser
   tests exercise both repeated actions.

One solve owns physical state, caches and controller lifecycle. Segment actions
operate on run-owned command handles; no generic GNC wrapping, configuration
replacement or physical state reset is introduced. Conditions use immutable
numerical spacecraft samples and copied full state, enforce a finite scalar and
an unsatisfied starting side, and preserve directed root semantics. Commands
invalidate cached derivatives after transitions. Priority callbacks precede
ordinary discrete control and saving; continuous callbacks retain solver event
ordering. Finalization closes the active segment once at actual solver end.
Propagation errors still throw.

Mission metadata preserves actual times independently of telemetry cadence.
Export retains exact boundary rows when present and refuses an insufficient
frame budget. No missing pose is synthesized. Old payloads retain their existing
behavior; schema and service version remain 1 with an optional mission block.
Core and companion Julia validators match, and JavaScript enforces the same
history relationships. Names and reasons reach the DOM through textContent.

## P1 Assessment

No unresolved P1 or P2 issues in the reviewed implementation. Vehicle topology,

remain fixed during a run. New workflows explicitly reject external propagation,
checkpointing and unqualified solver modes instead of silently changing settings.
Existing plans without segments retain their direct-solve parity.

## Residual Risk

Command actions are application-specific and must clear any held actuation that
should end; the executor does not automatically deactivate arbitrary controllers.
Reference changes take effect according to their controller's evaluation cadence.
External MuJoCo state, physics-ownership transfers, checkpoint resume and other
solver modes remain unsupported. Exact history can outlast saved trajectory
coverage; those viewer jumps are visibly unavailable. User actions and predicates
must obey their ownership and purity contracts. Local tests do not replace hosted
native, coverage, optional-package and documentation gates.
