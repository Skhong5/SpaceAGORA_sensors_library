## Residual Risk

This intentionally changes request-acceptance timing. The configured control
period determines when a new request can be considered. Guidance identity is
Δv, direction and source orbit; callers need a new source orbit for a repeated
identical command. Older scheduler checkpoints require the version that wrote
them or a new run. Explicit BurnPlanFamily installations have a separate contract.
Retained plans do not promise identical adaptive trajectories after arbitrary
changes to checkpoint placement.
