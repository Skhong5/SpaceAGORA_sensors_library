## Findings

No open findings. Local verification found four issues, each fixed before the push:

- **P2, `examples/common.jl`.** The environment switch loaded Pkg and called it in one top-level block. From the root project this failed with a world-age `MethodError`. It now calls `Pkg.activate` through `Base.invokelatest`; both projects run the quickstart, with identical results.
- **P2, root-project children.** Two probe children (`scenario_matrix_debug_probes.jl` and `xval_provenance_probes.jl`) and the full-arc runner's documented command loaded the scenario matrix, which imports Plots, in the root project. The children now run in the environment the tests run in, and the runner's usage and error text name `--project=examples`.
- **P3, GRAM loading contract.** The GRAMSuite retry's fallback is now the examples environment, so the test's expectation changed with it.
- **P3, root manifest.** The hand edit left a trailing blank line. The manifest is now byte-identical to Pkg's own rewrite of it.

## Residual Risk

- **The plotting stack floats.** A fresh examples or test setup takes the newest compatible plotting packages (listed in the body); only Roots is pinned, by decision. The PR body lists today's movements.
- **Scripts of your own.** A script that ran with `--project=.` and imports Plots or Roots before `examples/common.jl` must now use `--project=examples` or its own project; the Upgrading page says so.
- **The studies.** The scripts and launchers updated under `benchmarks/` were found by a static scan for imports of Plots or Roots before `common.jl`. Includes through computed paths are not resolved, and the studies themselves were not run. The remote job helper's new setup step was not run against a remote machine.
- **Agent environments.** `.github/workflows/copilot-setup-steps.yml` still prepares only the root project.
- **Windows and Julia 1.13.** The Windows workflow was not run locally. Its 1.13 job resolves the examples environment under 1.13, which may move packages; that job is not blocking.
- **Declaration drift.** The examples and test environments declare every root dependency. When the root gains one, both setups refuse until it is declared there too.
