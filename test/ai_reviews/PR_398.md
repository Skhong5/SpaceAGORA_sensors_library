# Review record: PR 398: gimballed thruster directions for the viewer

## Scope

Review of the SpaceAGORA `thruster-direction-frames` branch against main
(e5cc7d1ed). The core half of showing a gimballed thruster's turned cone and
plume in the viewer: a save field and a viewer-frames block; the viewer's
half is a change of the companion SpaceAGORAVisualizer.jl. One commit.

Authorship disclosure: this record was drafted by the author of the PR. The
plan assigns behaviour PRs of the actuator layer an independent reviewer (the
PI, or the second reviewer when available); this record does not replace that
review.

## Changed Files

- `src/orchestration/simulation/callbacks/save_fields.jl`: `_save_thruster_directions`, `thruster_direction_save_field` and `_thruster_direction_field_enabled` (the scene flag on and a gimbal mounted); `visualization_save_fields` adds the field.
- `src/orchestration/simulation/callbacks/registry.jl`: imports `thrust_direction`.
- `src/interfaces/analysis/visualization/scene/viewer_payload.jl`: the `thruster_direction` block of the viewer frames, built only when every column of a spacecraft's thrusters exists, and counted in the frame budget only then.

Outside `src/`: the output columns and outputs pages, tests.

## Findings

No P1 or P2 findings. Points a reviewer should check:

- Low, by design: the block is added to the frames only when present, so a
  run without gimbals writes the same payload as before (no `null` key).
- Low: the saved direction is the exhaust direction (minus the thrust
  direction, normalized), matching the scene glyph's `direction`; the viewer
  interpolates linearly between frames and normalizes.
- Low: the scene glyph JSON keeps the nominal direction; a viewer older than
  the companion change shows the nominal direction, as before.

## P1 Assessment

No P1 findings. Without a gimbal (or without the scene flag) the field is not
added and the payload is unchanged; the four fingerprints are bitwise
unchanged against main.

## Tests Added/Updated

- `test/unit/vehicle/thruster_gimbal_tests.jl`: with the scene flag on, the field is among the visualization fields, the saved exhaust direction is nominal before the gimbal's first tick and minus the turned thrust direction after it; no field without a gimbal.
- `test/unit/visualization/viewer_bundle_tests.jl`: the block is absent without its columns, carries stride, counts, offsets and total with the columns (three per thruster in scene order, frame-major), stays aligned under decimation, and is absent when any column is missing.
